# Support

Read the [user guide](docs/user/README.md), which has a troubleshooting section,
and [the README](README.md) first.
Use [GitHub Issues](https://github.com/Pirimera/PowerKit/issues) for reproducible bugs,
questions and feature proposals. Support is volunteer-based; there is no
response-time guarantee.

Include the app version, Windows build, ARM64/x64, whether PowerKit runs from an
installed package or as a development build, and steps to reproduce. Redact paths,
usernames and media metadata.
Use [private security reporting](SECURITY.md) for vulnerabilities.
