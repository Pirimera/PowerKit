# Support

Read [the README](README.md) and [testing/troubleshooting](docs/testing.md) first.
Use [GitHub Issues](https://github.com/Pirimera/PowerKit/issues) for reproducible bugs,
questions and feature proposals. Repository access is required while it is private.
Support is volunteer-based; there is no response-time guarantee.

Include app version, Windows build, ARM64/x64, installer versus raw executable and
steps to reproduce. Redact paths, usernames and media metadata.
Use [private security reporting](SECURITY.md) for vulnerabilities.
