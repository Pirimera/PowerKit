# Code of conduct

Be respectful, patient and specific. Critique work rather than people. Welcome
contributors regardless of background, identity, experience or language.
Harassment, threats, discriminatory remarks, unwanted sexual attention and
publishing another person's private information are not acceptable.

This applies to project issues, pull requests, reviews and other project spaces.
Maintainers may edit or remove harmful content, warn participants, restrict access
or ban repeated or serious misconduct. They should explain decisions when doing
so does not expose private information.

Report concerns to @Pirimera through an existing private contact channel. If none
is available, request one without naming affected people or publishing sensitive
details. For ordinary moderation requests, a neutral issue is also acceptable.
No separate confidential reporting address is currently configured.

Maintainers are expected to follow these standards themselves and consider appeals
in good faith. This is a small, maintainer-led project; there is no separate
moderation committee or guaranteed response time.
