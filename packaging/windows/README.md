# PowerKit

Native Windows 11 utilities: AlwaysOn, AlwaysTop, ScreenRuler, ImageResizer,
MediaRenamer, PowerStore and PowerMouse. The interface is available in Turkish, English
and Arabic.

The X button hides the window when a tray icon is available; use the explicit
exit button to stop the app. Manual sleep and closing the lid are not blocked.
AlwaysOn, AlwaysTop and ScreenRuler start off after every launch.

Preferences are stored in %LOCALAPPDATA%\PowerKit\settings.txt and remain after
uninstall. Microsoft Store delivers updates; PowerKit does not download updates
itself.

See [the project](https://github.com/Pirimera/PowerKit) for source, contribution
guidelines and the physical acceptance checklist. MIT terms are in LICENSE.
